# 🎮 Emoji Hangman

A polished emoji-based Hangman game built with **Python 3.11+** and **Tkinter**, developed for *CSE 2216 — Software Development I*.

## ✨ Features

- 🧠 **10-word campaign** across 3 levels (Easy → Medium → Hard)
- 🎯 **Emoji clues** for every word
- ⏱ **10-second timer** per word — with **Pause** support
- ❤️ **5 lives** per game
- 💡 **Hint system** (reveals one letter, costs 10 points)
- 🏆 **6 achievements** — First Win, 5 Streak, Hint Master, Speed Solver, Survivor, Champion
- 📊 **Player rating** based on achievement progress
- 🥇 **Persistent leaderboard** (top 10 with medals) — saved to `scores.json`
- 🗑 **Clear leaderboard** with confirmation dialog
- ⌨️ **Keyboard shortcuts**: `Enter` = guess, `Space` = pause, `Esc` = menu
- 🛡 **Graceful handling** of missing or corrupted save files
